# 小角 · DSH-Plus

应用名称为 **小角**，DSH-Plus 为插件名称。**小角**同时是统一 Logo 与吉祥物 IP；PC、Android、网页工作台和初始化使用同一形象。

2026-10-19 正式发布采用用户提供的新版“小角 IP · v2.1”素材：**浅米底、暖米白体、深墨豆形眼、砖红切角**。

- `dsh-plus-logo.svg` / `dsh-plus-logo.png`：来自 `02-应用图标`，用于桌面与手机图标、初始化、更新面板和连接入口。PNG 为 1024px。
- `dsh-plus-mark.svg`：来自 `01-主标识` 的透明底标准标识，适合与应用名称组合；保持 600:400 比例。
- `favicon.svg` / `favicon.ico`：来自 `06-网站favicon` 的圆点眼简化版；ICO 含 16 / 32 / 48 三尺寸。

品牌色：墨黑 `#222222`、暖米白 `#F3EBDF`、砖红 `#D44A36`、应用图标浅米底 `#EDE4D3`。不改身体、眼睛或切角比例，不拉伸、不加嘴或天线，不加渐变或描边。小尺寸采用简化版；Android 自适应启动器保留系统遮罩安全区。

正式母版来源：`xiaojiao-IP/小角IP/`。本目录拷贝正式素材作为运行与 CI 的唯一品牌资产来源，原始目录不参与构建。母版中的 RouterGo 只是历史文件名，不作为产品展示名称；`dsh-plus-*` 文件名保留以兼容现有构建和插件引用。模型供应商仍使用各自品牌。

已接入：网页 PC/移动工作台 favicon、连接入口、设备中心与更新面板；Android 启动器与启动页；Windows 窗口、托盘、快捷方式、安装器及自有初始化页面。PC 初始化复用官方 skip 接口进入工作台，不修改官方主进程或凭据。
