# 设备切换与服务器接入

日期：2026-10-19。状态：已实现，验证边界见文末。官方 Harness pin 保持 upstream.json，不修改官方子模块。

## 用户路径

侧栏新增“设备”入口；本地设备管理页独立于远端工作台，离线也能返回并切换。保存多台电脑/服务器，选择后在同页工作台区域打开完整 Harness，不重做聊天。切换仅关闭客户端流，不停止主机任务。Android 使用原生本地入口及加密多设备存储；电脑通过本机插件提供的本地设备中心接入。

添加电脑粘贴 Link 配对地址，等待目标电脑批准；两台电脑双向连接分别授权。添加服务器输入名称、SSH 地址/端口/用户名、密码或密钥；先确认主机指纹，再认证、检查、安装/复用、启动、授权并进入工作台。密码仅在本次连接内存使用，不持久化；每个设备独立访问令牌和工作台位置，不自动替换发送目标。

## 边界与安全

- Node 本地设备中心监听 127.0.0.1 随机端口，以短期一次性引导码交换随机会话路径（兼容桌面跨站 iframe，不依赖第三方 Cookie）；所有写操作校验同源及 JSON 请求，远端工作台禁止访问设备管理接口。
- Node 已授权设备令牌保存在本机 Link 数据目录的私有权限文件，遵循官方本机凭据文件的同 OS 用户信任边界；不声称具备系统钥匙串隔离。Android 使用 Keystore AES-GCM 加密。SSH 密码/私钥默认仅内存。
- SSH 首连返回 SHA256 主机指纹，用户明确确认后使用原值校验；指纹变化阻止认证。默认 SSH 隧道，仅转发服务器环回 Link HTTPS 端口，工作台端口不暴露公网。断线显式重连，不自动把消息发给另一台设备。
- Linux 首版支持有 systemd 用户服务的 Ubuntu/Debian、x64/arm64。复用已有受支持安装，不覆盖项目或历史；不静默提权。安装器固定版本/提交，外部下载需校验。停止、重启、日志、升级与移除本机连接分开。
- 浏览器不能直接 SSH，使用本机设备中心；Android 原生 SSH 不依赖电脑常驻。不能到达的主机显示未知/离线，不能伪装在线。

## 接口契约

本机官方 owner 通道 POST `/api/commander-devices` 仅有 `action: launch`，返回 `{url}`，进入本地设备中心。不透传给配对工作台。

设备中心同源 POST `/api/devices`，JSON `{action,...}`：

- `list` → `{devices,activeId,capabilities}`，设备公开记录 `{id,name,kind,url,status,lastError}`，不返回令牌、密码、私钥。
- `pair` `{uri,name}` → `{requestId,expiresAt}`（pollToken 仅服务端保存），`pairStatus` `{requestId}` → `{status,device?}`。
- `select` `{deviceId}` → `{device,url}`；`rename` `{deviceId,name}`、`remove` `{deviceId}`。移除不撤销目标授权，不卸载服务。
- `sshProbe` `{host,port,username}` → `{fingerprint}`；`sshConnect` `{host,port,username,name,fingerprint,password?,privateKey?,passphrase?,source?}` → `{jobId}`。首次确认指纹后调用。
- `job` `{jobId}` → `{id,state,steps,error?,device?}`。`reconnect` `{deviceId,password?,privateKey?,passphrase?}` 重新建立服务器隧道。
- `serverAction` `{deviceId,operation}`，operation 为 `status|start|stop|restart|logs|update`。

SSH 服务模块导出 `createServerManager({directory,onDevice})`，提供 `probe(input)`、`connect(input)`、`job(id)`、`reconnect(input)`、`manage(input)`、`close()`；onDevice 接收含 `{id,name,kind:'ssh',url,pin,token,ssh:{host,port,username,fingerprint}}` 的私有设备记录。建立隧道后 url 为本机环回 HTTPS 地址。连接 API 返回任务 ID，前端轮询进度；失败保留旧连接。

设备中心代理 `/s/<session>/link/workbench/` 下完整远端资源，认证 Cookie 留在服务端；每台设备独立环回端口与浏览器源，随机会话路径鉴权，iframe 隔离存储。远端工作台 bridge 以 document.baseURI 解析基址。桌面/移动端顶部均提供始终可用的本机设备返回入口。

OpenAPI 契约文件放 `plugins/link/openapi.json`，覆盖本轮设备 API。MCP 的 delegation 接口与权限不变：不向 Agent 暴露主机添加、SSH 凭据或设备切换能力，避免 Agent 改变用户当前发送目标。

## 2026-10-20 Web 502 与 SSH 可选原生扩展

- 服务器 Node.js 24 加载以系统 Node.js 22 编译且硬链接 libnode.so.127 的 sshcrypto.node 与 cpufeatures.node，造成 V8 运行库混载；隔离子进程导入 ssh2 后 6/6 SIGSEGV，空脚本 6/6 正常。服务反复退出期间反向代理返回 502。第三方加载异常被 catch 仍不能消除原生崩溃。
- 线上隔离这两个可选构建物，使用 ssh2 自带 JavaScript/Node crypto 回退；保留凭据、会话和 SSH 功能，不修改上游源码。源码构建先清理两个可选生成目录；发行包不携带 ssh2 的 crypto/build 本机构建目录及 cpu-features 可选依赖，防止开发机 ABI 产物跨 Node/Electron 传播。
- SSH 连接接口与权限、MCP/OpenAPI 不变；验证需含真实 SSH 握手/传输、生产 Node 子进程正常退出及认证站点状态，不能只看 systemd active。
